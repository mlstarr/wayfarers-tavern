# Wayfarer's Tavern

Run a tavern at a fantasy crossroads. Recruit procedurally generated adventurers, send them on real-time quests, and read what the dice decided.

Play: https://mlstarr.github.io/wayfarers-tavern/

Testing tip: add `?fast` to the URL to make quest timers run 60 times faster.
